# Images embarquées

Des images embarquées plutôt que chargées par le réseau : l'écran d'accueil est
le tout premier que voit une personne qui vient d'installer l'app, parfois sans
connexion. Une image distante y laisserait un trou.

  transparent d'après la luminosité). À refaire si l'icône change.
