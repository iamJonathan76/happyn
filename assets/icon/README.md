# App icon

Dépose le logo HAPPYN ici, nommé **`happyn.png`**.

- Format : **PNG carré**, idéalement **1024×1024**
- Le « H » dégradé sur fond sombre (full-bleed, pas de transparence)

Puis génère les icônes Android + iOS avec :

```
dart run flutter_launcher_icons
```

La config est dans `pubspec.yaml` (section `flutter_launcher_icons`).
